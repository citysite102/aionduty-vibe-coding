# 錯誤訊息判讀對照表

看到紅字不用慌，也不需要看懂那段英文。你只要做三件事：**分辨它出現在哪裡、找出它在說什麼、用對的方式交給 AI。**

---

## 第一步　先看紅字出現在哪裡

位置決定了問題的性質，這比讀懂內容更重要。

| 出現在哪裡 | 代表什麼 | 怎麼看到 |
|---|---|---|
| **終端機** | 還沒跑起來就出事，專案本身啟動失敗 | 你下指令的那個黑色視窗 |
| **瀏覽器 Console** | 跑起來了，但畫面壞掉 | 網頁上按 F12（Mac 按 Cmd + Option + I），點「Console」分頁 |
| **兩邊都沒有紅字，畫面卻是空白** | 程式沒出錯，但東西沒畫出來 | 見本表最後一節 |

---

## 第二步　每一段紅字都在講三件事

不管多長，都只回答這三個問題。找到答案就夠了，不必逐字讀懂。

1. **在哪裡出事**　哪個檔案、第幾行
2. **出了什麼事**　它想做什麼、卡在哪
3. **接下來該做什麼**　多半 AI 會告訴你

---

## 終端機常見紅字

| 你會看到 | 白話意思 | 通常怎麼解決 |
|---|---|---|
| `command not found: npm` | 這台電腦還沒裝這個工具 | 先裝工具本身，不是專案的問題 |
| `sh: vite: command not found` | 專案要用的工具還沒裝 | 跑 `npm install` |
| `Module not found: Can't resolve './xxx'` | 程式要載入一個檔案，但找不到 | 檔案還沒建立、檔名拼錯（含大小寫）、或放錯資料夾 |
| `ENOENT: no such file or directory` | 同上，路徑指到不存在的東西 | 確認檔案真的在那個位置 |
| `SyntaxError: Unexpected token` | 程式碼打錯字 | 多半是少了括號、引號或逗號 |
| `Port 3000 is already in use` | 這個門牌已經有人在用 | 關掉另一個正在跑的視窗，或換一個埠號 |
| `EACCES: permission denied` | 權限不足 | 通常是裝在系統目錄，換個位置或問 AI |

---

## 瀏覽器 Console 常見紅字

| 你會看到 | 白話意思 | 通常怎麼解決 |
|---|---|---|
| `Cannot read properties of undefined (reading 'xxx')` | 程式想拿一個東西，但手上是空的 | 常見原因是資料還沒回來就先畫，整段貼回去請它修 |
| `xxx is not defined` | 用到一個沒有定義過的名字 | 拼錯，或忘記把它引進來 |
| `Failed to fetch` | 打電話給後端，沒人接 | 後端沒啟動，或網址打錯 |
| `CORS policy` 開頭那一長串 | 後端不允許你的網頁跟它要資料 | 這是後端設定問題，把整段貼給 AI |
| `404 (Not Found)` | 那個網址上沒有東西 | 路徑打錯，或檔案沒有上傳 |
| `500 (Internal Server Error)` | 後端自己出事了 | 不是畫面的問題，去看後端的紅字 |

---

## 第三步　怎麼把紅字交給 AI

**整段複製貼上，不要只貼一句，也不要自己翻譯。** 錯誤訊息的前後文對它很有用。

三句萬用問法，看情況挑一句：

- 「用白話解釋這個錯誤在說什麼，我不看程式碼。」
- 「請只改必要的地方修好它，並告訴我你改了什麼。」
- 「這次為什麼會發生？下次我要怎麼避免？」

第三句最容易被跳過，但它是你會不會一直踩同一個坑的分水嶺。

---

## 沒有紅字，畫面卻一片空白

這種最讓人慌，因為沒有東西可以貼。你有兩招，都不需要看懂程式碼。

**一、直接給它看**
截圖，貼給它，然後說：「這是我現在看到的畫面，OO 本來應該在這裡，請幫我修正。」

**二、去撈瀏覽器的紅字**
1. 在網頁上按 F12（Mac 按 Cmd + Option + I）
2. 點最上面的 **Console** 分頁
3. 看到紅字就整段複製，貼回去說：「這是瀏覽器 Console 的紅字錯誤，請幫我修復。」

不用看懂那段紅字，它看得懂。

---

## 三件不要做的事

- **不要在還沒搞懂原因前亂改別的地方。** 一次改一個地方，改完再跑一次。
- **不要只貼錯誤的最後一行。** 前面那幾行通常才有檔名跟行號。
- **不要因為看不懂就跳過。** 紅字是目前為止最誠實的回饋，它明確告訴你哪裡卡住了。

---

## 出錯當下的檢查順序

1. [ ] 紅字出現在終端機還是瀏覽器？
2. [ ] 找到檔名與行號了嗎？
3. [ ] 整段複製了嗎（不是只有一行）？
4. [ ] 貼給 AI 並說明你原本想做什麼
5. [ ] 它改完之後，問一次「你改了什麼」
6. [ ] 重跑一次，確認紅字真的不見了
