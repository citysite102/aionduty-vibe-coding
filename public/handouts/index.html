課程講義

前三份搭配「Agent 運作框架」那一段：先用模板寫出第一份手冊，卡住的時候查判斷卡， 過一陣子用檢查表整理一次。第四份是看到紅字的時候翻的。已依 Claude Code 最新官方 memory 文件核對。 第五份是範例專案的下載位置，手上沒有自己做的計時器時用它接著做。

列印版（四份合一） A4 四頁，開啟後直接列印或另存 PDF。填寫欄位是底線，印出來可以手寫。上線前自查卡沒有收進來，它是對著專案跑的，不是填表。 print.html 1. CLAUDE.md 模板 複製到你的專案根目錄，改名為 CLAUDE.md。也可放在 ./.claude/CLAUDE.md；先用根目錄版本，最容易看見。 claude-md-template.md 2. 規則歸位判斷卡 一條規則該放 CLAUDE.md、Skill、Hook 還是 CI。附「它沒照做時先查這五件事」。 routing-card.md 3. 五步健檢檢查表 手冊越寫越長的時候用。盤點、減法、歸位、加法、修剪，含哪幾條可以直接刪、說不準的怎麼放。 health-check.md 4. 錯誤訊息判讀對照表 看到紅字的時候用。終端機與瀏覽器常見錯誤的白話對照，以及畫面空白卻沒報錯時怎麼辦。 error-guide.md 5. 上線前自查卡 東西做完、要交出去之前用。八題不用讀程式碼的自查、三種檢查各自抓得到什麼、OWASP Top 10 十條對照、接了 AI 多出的兩類風險，以及金流、個資、法遵、著作權各自那一題會出事的。 ship-check.md 6. 範例專案：任務計時器 手上沒有計時器的人用這一份。按綠色的 Code → Download ZIP，不用登入。解壓縮之後用 Claude Code 打開裡面的 mission-timer 資料夾，動手那幾頁照原樣走得完。 github.com/citysite102/mission-timer-v2

完整教學案例

五份 PDF，每一份從空資料夾走到上線。先寫規格，再做網站。 都標明了閱讀與動手各要多久，沒有程式背景也走得完。檔案大，建議在 Wi-Fi 下載。

課前作業：規格文件怎麼寫 案例一開始之前先寫完這一份。七個區塊寫成一份 spec.md：一句話定義、不做什麼、真實素材、參考方向、硬性限制、驗收條件、素材清單。判斷標準只有一句，這一條是形容詞，還是可以被檢查的條件。 case-01-spec-writing.pdf ・ 2.4 MB ・ 60 到 90 分鐘 案例一：器 VESSEL，陶藝工作室一頁式網站 把「我想要這樣」變成 AI 能穩定執行的規則。沒有資料也沒有表單，所以不需要任何工具。使用 Astro、TypeScript、原生 CSS 與 Vercel。 case-01-vessel.pdf ・ 8.0 MB ・ 閱讀約 1.9 小時，動手約 5.7 小時 案例二：東京環状 24 時，捲動穿越的 3D 藝廊 判斷什麼問題該用什麼技術，每一個工具都要說得出它在解決什麼問題，以及不用它會怎樣。十張照片沿深度排開，捲動時鏡頭穿過它們。使用 Three.js、GSAP 與原生 CSS，不需要看懂 shader 或 JavaScript。 case-02-tokyo-loop.pdf ・ 6.6 MB ・ 閱讀約 2.6 小時，動手約 8.6 小時 案例三：開窯預約，有帳號與資料的網站 哪些事情不能只相信前端。有人繞過網頁直接送請求的時候，擋得住的只有資料庫的規則。可以登入、預約、取消，而且只看得到自己那幾筆。使用 Astro、Supabase 與原生 CSS，不需要看懂 SQL。 case-03-kiln.pdf ・ 6.2 MB ・ 閱讀約 2.5 小時，動手約 7.8 小時 案例四：海上許願神社，3D 場景加上會員登入 改完之後拿什麼證明其他東西沒壞。海中央一座神社，點水面起漣漪、船跟著浪起伏、白天黃昏夜晚會轉換，有背景音樂、信箱登入，以及一支要帶登入權杖才拿得到資料的 API。使用 Three.js、Astro、Web Audio 與 Supabase，不需要看懂 shader 或 JavaScript。聲音素材要自己準備。 case-04-wishes.pdf ・ 23.4 MB ・ 閱讀約 4.9 小時，動手約 16.3 小時

回去之後的第一件事：把模板複製到你手上真正在跑的專案，填完之後開一個新對話， 輸入 /context，確認 CLAUDE.md 出現在 Memory files 清單裡。沒被載入的規則，寫得再好都沒有用。

想不起來某一句指令怎麼打：課程裡出現過的指令都收在 課程工具箱的「指令速查」， 照章節排，可以直接複製。同一個工具箱裡還有 Prompt 組裝器、CLAUDE.md 產生器與規則歸位器。
