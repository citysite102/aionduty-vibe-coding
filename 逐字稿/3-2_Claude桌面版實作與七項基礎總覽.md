## Slide 18｜桌面版五步，從下載到講第一句話

**畫面**
sky 膠囊「現在開桌面版」／五張步驟卡：下載桌面版／登入並選方案／切到 Code／選一個資料夾／講一句話／一塊「左邊那一排先不用管」／最下面 sky 框「這一格不是簡化版」。

**逐字稿**

> 好，接下來直接動手。現在把桌面版打開，跟著做一次這五步。五步做完，你的電腦裡會多出一個可以打開的網頁。
>
> 這一段的目的不是要你做出一個好東西，是要你親眼看到檔案從無到有長出來。那個畫面看過一次，後面所有的說明才會有地方掛。
>
> 第一步跟第二步，課前準備那張清單上已經有了：到 claude.com/download 下載，Mac 跟 Windows 都能裝；帳號要有額度，Claude Pro 月費二十美金直接登入，或者到 Console 儲值，最低五塊美金，按用量扣。
>
> 這兩種付法的差別，成本那一段會整個攤開來算。現在不用比，選一個先進去就好。真的沒有概念的話，先儲五塊美金試水溫，是這兩條路裡面退場成本最低的那一條。
>
> 第三步開始是新的。打開之後看左上角，那裡有兩個小圖示，一個是對話框，一個是角括號包著斜線的 `</>`。按 `</>` 那個，那就是 Code。
>
> 你如果打開看到的是上面三個頁籤 Chat、Cowork、Code，那是另一個版本的版面，選 Code 那一個就對了。我錄的時候官方文件寫的還是三個頁籤那一版，但我手上的 app 已經換成圖示了。這種地方會一直改，你認的是名字，不是位置。
>
> 第四步，它會要你選一個資料夾。選桌面就可以。
>
> 這一步很多人會停很久，想說要不要開一個正式的位置。不用。它問的不是「你要把作品放哪裡」，是「你現在允許它在哪個範圍裡動」。選定之後，它就在這個範圍裡讀寫，不會跑出去。
>
> 第五步，打一句話進去：「幫我做一個五分鐘的計時器網頁。」中文就可以，不用寫程式碼。
>
> 打之前先看一眼左邊那一排：Projects、Artifacts、Scheduled、Design、Customize。這些我知道很吸引人，但它們是 Claude 對話那一側的功能，跟你現在要做的事沒有關係，先不用管，要用到的時候會回來講。
>
> 還有輸入框上那個 Chat 跟 Cowork 的切換。Chat 就是一般對話。Cowork 是讓它綁一個資料夾，自己去跑比較長的工作，它讀得到也寫得到那個資料夾，但它不執行指令。這門課走的是 Code，因為後面要做的版本控制、驗收、部署，那幾件事 Cowork 做不到。三個地方到底差在哪，後面會整個攤開來比一次，現在知道你要按的是 `</>` 就好。
>
> 然後就看著它做。你會看到它自己決定要建哪幾個檔案、自己把檔案寫出來、有些動作還會先停下來問你要不要放行。
>
> 【等待 Agent 執行，不補旁白】
>
> 看的時候不要急著判斷它做得漂不漂亮，先看那個資料夾。裡面真的多出了東西，那就是「有腦，也有手」的那隻手。
>
> 這一個是試跑。正式的作品之後會在同一個地方另外開一個資料夾重做，所以這裡做壞了、做醜了、或者做出來跟你想的不一樣，都不要緊，不用回頭修。
>
> 最後這一格處理的是一個很常見的誤會：有人以為桌面版是給新手用的簡化版，厲害的功能要裝終端機才有。
>
> 不是。桌面版的 Code 頁籤跟終端機裡的，是同一個 Claude Code，只是換了一個介面。你現在只要記住一件事：之後換介面的時候不用重學。

**這頁的教學意圖**：親手看到檔案長出來；知道左邊那一排現在都可以不管；知道桌面版不是簡化版，之後換終端機不用重學。
**預估時間**：7 分鐘（含實機）

## Slide 19｜Vibe Coding 需要的軟體基礎知識

**畫面**
開場 sky 底框：前面那幾步不用懂這些也跑得動。下面這幾樣是出事的時候，你才知道要去哪一層找。
七格卡片，每格一行「會卡在哪」加一個標籤（概念說明／動手·瀏覽器／動手·桌面版）。

**逐字稿**

> 你剛剛看到了，現在做出一個能動的小工具有多容易。五個步驟，你一樣東西都不用懂。
>
> 所以看到接下來這七格，你可能會想：既然不懂也做得出來，那為什麼要學？
>
> 這七樣加起來，是一個軟體怎麼被組起來的：一個動作會經過哪幾層、資料停在哪裡、哪一層會先到極限，還有為什麼當初要這樣分。知道這個，你才問得出對的問題，也才判斷得了它給你的做法合不合理。
>
> 每一格下面那一行寫的不是它是什麼，是不學它你會卡在哪。先用這個角度看一次。
>
> 第一，看懂紅字。卡點是「紅字一出現就不敢動」。這一格排第一，因為它是最早會撞到的，而且它其實不是壞事，那是唯一會主動告訴你問題在哪裡的東西。
>
> 第二，API 與資料格式。卡點是想接外面的資料，看不懂文件。你想讓網頁去抓天氣、抓匯率、抓一份現成的資料，路就在這裡。這一格標著動手，而且它是可以點的，點下去會直接開 Claude 的 API 文件，等一下那一段就拿它來看。
>
> 第三，前端與後端。卡點是壞了不知道要去哪一層找。這一格跟第一格是一組的：紅字告訴你出事，這一格告訴你出事的地方在哪一層。
>
> 第四，資料庫。卡點是關掉瀏覽器，剛存的就不見了。這是自己做東西的人最常撞到的一堵牆，而且撞到的時候通常想不到是這個原因。
>
> 第五，上線部署。卡點是只有自己電腦打得開，傳不出去。你剛才做出來的那個計時器現在就是這個狀態，它活在你的桌面上，傳不給任何人。
>
> 第六，Git 版控。卡點是改壞了回不去上一版。讓 AI 動手之後，這一格的重要性會比你自己寫的時候更高，因為它改動的速度比你回想的速度快。
>
> 第七，Claude Code。這一格處理的是你手上那個工具本身：介面上哪些東西要理，有哪些按鍵，還有它認得哪些指令。
>
> 七格裡面有兩格標著動手，其他五格是概念說明。標動手的那兩格會離開簡報，實際開畫面操作。
>
> 回到剛才那個問題：不懂也做得出來，為什麼要學？因為做得出來跟修得好是兩件事。東西順的時候你確實不需要這七格，可是它一出事，你連該問什麼都問不出來，只能回頭跟它說「還是壞的」，然後看它亂改。
>
> 還有一個更後面才用得到的理由：這幾層的名字是業界通用的。你之後要把做法交給同事，或者接手別人做到一半的專案，講的是同一套詞，不用重學。

**這頁的教學意圖**：七樣基礎的定位是「出事時去哪一層找」，不是入場條件。
**預估時間**：4 分鐘
