## Slide 42｜選修：終端機與 Claude Code 安裝（分節頁）

**畫面**
分節頁，編號寫的是 EXTRA 不是數字。副標 Optional: The Terminal Track。下面一條四塊的路線圖：終端機是什麼（3）、換一個好用的（2）、裝 Claude Code（3）、終端機才有的按鍵（2）。

**逐字稿**

> Hello，我是 Samuel。這一章的編號不是數字，是 EXTRA，因為這一段跳過去，不會少掉任何東西。
>
> 前面每一段都要走完才接得下去，這一段不是。
>
> 為什麼要分出來。你前面做出來的那個計時器，從頭到尾都是在桌面版的視窗裡做的，你沒有打過一行指令。那是刻意的安排，因為有一批人的電腦本來就裝不了東西，公司的機器管得緊，或者根本不是自己的機器。那些人如果被卡在安裝那一關，後面全部都做不了。
>
> 所以終端機搬到這裡，放在你已經有作品之後。你可以現在看，也可以之後某一天真的需要了再回來看。
>
> 那什麼時候會真的需要。有三種情況。第一種，你想同時開好幾個 Claude 在不同的資料夾裡跑，桌面版一次只顧一個專案。第二種，你要用的某個功能只有終端機版有，後面按鍵那一頁會講到幾個。第三種，你已經在用別的終端機工具，想把 Claude 接進去。三種都沒有的話，桌面版夠用。
>
> 這一段的四塊，第一塊最寬，是終端機本身在幹嘛，會有幾個指令讓你實際按按看。第二塊是換一個比較好打字的終端機，可換可不換。第三塊是把 Claude Code 裝起來，實際上就是一行指令加一次登入。第四塊是終端機版才有、桌面版沒有的那幾個按鍵。

**這頁的教學意圖**：這一段是可以整段跳過的，以及什麼情況下你才需要回來看。
**預估時間**：2 分鐘

## Slide 43｜選修：終端機基本指令

**畫面**
上方一條說明帶。左邊面板有兩個分頁：「常用生存指令」列七顆可以按的指令，「打字快捷鍵包」列六組 Ctrl 鍵。右邊上半是專案目錄樹狀圖，下半是一個會逐字打字的模擬終端機，最底下一條會跟著換的指令說明。

**逐字稿**

> 終端機那個黑畫面，大概是這門課裡最容易讓人退卻的東西。所以先把它講小一點。
>
> 它就是一個用打字命令電腦的視窗。你平常做的事它都做得到：點開資料夾、打開檔案看內容、在一堆檔案裡找一個字、新增一個資料夾。差別只在你不是用滑鼠點，是打一行字。
>
> 那你為什麼要看得懂它？這一題就是這一整段的理由所在：Claude 在你的電腦裡幹活的時候，用的就是這些指令。你叫它「把這個專案裡所有提到 API 的地方找出來」，它不是用眼睛看，它是打了一行 `grep`。所以你看得懂這幾個字，你就知道它剛才在你的電腦裡做了什麼，而不是只看到它回你一句「我找到了」。
>
> 我們從左邊按下去。第一顆，`pwd`，印出我現在站在哪一個資料夾。注意它印出來的是一條從最上層開始的完整路徑，這叫絕對路徑。你會需要它，是因為終端機不像檔案總管有一個視窗告訴你在哪，你得自己問。
>
> 第二顆，`ls`，列出這個資料夾裡有什麼。它跟你在檔案總管裡看到的是同一批東西，只是排成文字。
>
> 第三顆，`cd`，換一個地方站。我打的是 `cd ~/Desktop`，那個波浪號代表你的家目錄，所以整句就是「切到桌面」。這一顆要注意它的回應：成功的時候畫面上什麼都不會出現。
>
> 終端機的慣例是沉默代表成功，沒有紅字就是做好了。這件事第一次看非常不習慣，你會以為它壞了，然後再按一次。我自己第一次用也是這樣。
>
> 第四顆，`cat`，把一個檔案的內容整個倒在畫面上。我開的是 `package.json`，這個檔案等一下會在課程裡再遇到好幾次，它記的是這個專案用了哪些別人寫好的套件。
>
> 第五顆跟第六顆是同一個字，`grep`，找東西。先看單純的那個：在 `package.json` 裡面找含有 dependencies 的行，結果只印出那一行，其他幾十行全部不印。它的職務就是篩掉你不想看的。
>
> 第六顆加了兩個字母，`-rn`，意思變成「往下鑽進每一層資料夾，而且告訴我第幾行」。結果你看到的是檔名、冒號、行號、冒號、那一行的內容。這是 Claude 在陌生專案裡最常用的一招：它不會把整個專案讀完，它先 `grep` 一次，找到相關的那幾個檔案跟行號，再只讀那幾段。後面講到怎麼省錢的時候，你會再看到這個行為。
>
> 最後一顆，`mkdir`，建一個新資料夾。按下去你看右上角，樹狀圖裡長出一個 `utils/`。這是這一頁唯一會改到畫面的指令，其他六顆都只是在讀。順便也印證了沉默代表成功那件事：它建好了，但終端機那邊什麼都沒說。
>
> 上面那排還有第二個分頁，打字快捷鍵。終端機的預設行為是滑鼠點不到字，你想把游標移到句子中間不能用點的，所以有這幾個鍵。裡面最該記的是兩個：`Ctrl + C` 是喊停，程式跑不停或你打到一半想全部清掉，按它；`Ctrl + L` 是把畫面清乾淨，跑久了滿滿一片字的時候用。我按一下給你看。
>
> 還有一個 `Tab`，補全。檔名打一半按它，剩下的它幫你補完。長檔名不要自己打完，很容易打錯一個字母然後找不到原因。

**這頁的教學意圖**：認得出 Claude 在你電腦裡實際執行的那幾個指令，尤其是 `grep`，以及「沉默就是成功」這個慣例。
**預估時間**：6 分鐘（動手）

**【轉場 → Slide 44】**

> 這幾個指令在哪一台電腦上都一樣。會不一樣的是你打字的那個視窗好不好用，那個是可以換的。

## Slide 44｜選修：Warp 終端機的三個特點

**畫面**
上方一段對照（傳統終端機 vs Warp），中間三格特點：像編輯器一樣好打字、內建 AI 提示、Warp Drive 存常用指令。下面兩條，一條推薦理由，一條用 amber 標的提醒：不裝也不影響後面。右邊一塊 Warp 官方示範的連結區。

**逐字稿**

> 終端機那幾個 Ctrl 鍵之所以存在，是因為傳統的終端機視窗裡滑鼠幾乎沒有用。打錯一個字想回去改，你得按 `Ctrl + A` 跳到行首再一格一格移過去。
>
> 這件事一天做二十次就會很煩，而且它煩的不是難，是瑣碎。
>
> Warp 是一個把這件事修掉的終端機。它只有一個身分要先講清楚：它是「視窗」，不是新的一套指令。前面那七個指令，在 Mac 內建的終端機、在 Windows 的終端機、在 Warp 裡面，打起來一模一樣。
>
> 第一個特點修的就是游標那件事：滑鼠點哪裡游標就去哪裡，複製貼上照你平常的習慣，還會提醒你拼錯字。對於不常用終端機的人，光這一條就省掉很多挫折。
>
> 第二個是它內建 AI。按一個 `#`，然後用中文講你想幹嘛，例如「幫我把佔用 3000 這個連接埠的程式關掉」，它把指令寫出來給你。這個功能跟這門課的主題有點重疊，你之後大部分的事情是交給 Claude Code 做的，但偶爾你會需要一個跟專案無關的系統指令，那時候它很方便。
>
> 第三個是 Warp Drive，把調通的指令存起來。這個功能要用到的時機比較晚，等你有一組每次上線都要跑的指令的時候才會想到它。
>
> 這三個功能它自己也一直在改。你要判斷的是換一個終端機值不值得，不是記它現在有哪幾樣。
>
> 還有一句最重要的：不裝也不影響後面的課程。
>
> 裝工具最容易變成拖延的藉口。裝了一個發現要設定，設定完又看到另一個推薦，一個下午就過去了，東西一個都沒做。Mac 內建的終端機、Windows 內建的終端機，做完這門課全部的內容都夠用。Warp 是舒適度的選擇，不是必需品。
>
> 如果你想試，它 Mac、Linux、Windows 都有，官網在畫面上。

**這頁的教學意圖**：換終端機只是換視窗，指令不變；而且這件事完全可選。
**預估時間**：3 分鐘

### 1.【缺漏】`10_M1_TerminalBasics.tsx` 左下角的說明區在「常用生存指令」分頁是空的

- 那一塊寫死了 `activeTab === 'commands' ? '' : '點擊右方帶有「模擬鍵」的快速鍵⋯'`。切在指令分頁時，畫面上會留一顆孤零零的 💡 後面什麼字都沒有，而那正是這一頁一打開的預設狀態。
- **建議**：兩種改法選一種。補一句對應的說明（例如「點左邊任何一顆指令，右邊的終端機會實際跑一次」），或者整塊改成 `activeTab === 'shortcuts' && (...)`，指令分頁時不要渲染。
- 補字的話留意 D-2「課務與操作交代」那條：畫面上的操作說明容易變成廢話，寫「跑完會看到什麼」比寫「點下去」好。

### 2.【矛盾】`cd` 的說明把後面才出現的安裝頁講成已經發生過

- 原文：「安裝那一頁叫你『切到你想放作品的地方』，用的就是這一個。」但安裝頁是 Slide 45，在這一頁之後。
- **建議**：改成指向未來的說法，「等一下裝 Claude Code 的時候會叫你切到想放作品的地方，用的就是這一個」。同一個問題在這門課犯過兩次（CLAUDE.md B-4），改完順手用「那一頁」「上一頁」掃一次這兩支選修頁。

### 3.【語法】`10a_M1_WarpTerminal.tsx` 有兩個 `stepIndex={2}`

- 左邊三格特點的第一格是 `stepIndex={2}`，右邊 Warp 官方示範那一塊也是 `stepIndex={2}`。左右兩欄同時出現才可以共用號碼（CLAUDE.md A-2），但這兩塊講的不是同一件事，右邊那塊在講整個工具的樣子，跟「像編輯器一樣好打字」沒有對應關係。
- **影響**：講者講到第一個特點的時候，右邊整塊示範會一起跳出來搶注意力。
- **建議**：右邊那塊改成 `stepIndex={1}`，跟開場的對照一起出現（它是「Warp 長這樣」的一部分），左邊三格維持 2、3、4。

### 4.【缺漏】`07b_Div_TerminalTrack.tsx` 沒有說「跳過這一段會不會影響後面」

- 檔頭註解寫得很清楚（放在章節三收成之後，跳過不會少掉前面用得到的東西），但那是給維護的人看的，學員看不到。畫面上只有 EXTRA 跟 Optional 兩個字。
- 逐字稿已經口頭補了，但分節頁是整段唯一的入口，學員翻講義的時候只會看到路線圖。
- **建議**：路線圖上方或 `SectionDivider` 的副標補一句「跳過不影響後面的章節」。不用展開理由。
