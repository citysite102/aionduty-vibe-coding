## Slide 44｜裝好終端機版，確認它讀得到你的專案

**畫面**
sky 的 Callout 說明這一段是選修。中段「前置準備」三個要自己下載安裝的東西，底下三行驗證指令。再來是安裝 Claude Code 的三組指令（Mac、Windows、npm 備案）。最後兩塊：切到專案問它一句話，以及兩邊可以隨時換。

**逐字稿**

> Hello，我是 Samuel，歡迎來到這個單元。
>
> 開頭這個框先把身分講清楚，因為這是最常見的誤會：終端機版跟桌面版是同一個 Claude Code，不是另一個工具。
>
> 你裝它，不會得到一個更聰明的 AI。它們背後是同一個。
>
> 那為什麼還要裝。三個理由。第一，它可以同時開好幾個，一個資料夾一個視窗，各跑各的。第二，有一個 `!` 開頭的直通指令只有它有，下一頁會講。第三，你之後想把它接進自動化流程，例如每天定時跑一次，那需要終端機。這三件事現在對你都還不急，所以這一段是選修。
>
> 接下來是前置準備。這裡有一個很容易搞混的地方，我一定要先講：這一區分成兩塊，上面三樣是你自己開瀏覽器去下載安裝的，下面三行才是用打的。
>
> 不要把上面那三樣拿去終端機打，也不要拿去跟 AI 講。這個錯我看過不只一次，而且卡住的人通常不知道自己卡在哪，因為畫面只會回一句看不懂的話。
>
> 上面三樣：VS Code 是編輯器，你要一個地方看檔案跟開內建終端機。Node.js 選 LTS 版本，要 22 以上，它會順便把 npm 一起裝好。Git 在課前那份清單裡就有了，裝完之後你不用管它，之後所有 Git 的指令都是 Claude 幫你打。
>
> 裝完之後開 VS Code 的內建終端機，把下面三行各打一次。每一行都是問「你裝好了嗎」，回你一組版本號就代表好了。Mac 如果以前裝過 Xcode 的命令列工具，Git 通常已經在了；Windows 預設沒有，要自己裝。
>
> 然後是 Claude Code 本身。官方首選是原生安裝器，Mac 跟 Linux 一行、Windows 一行，注意 Windows 那行要在 PowerShell 裡跑，不是舊的 cmd。你如果已經有 Node.js，也可以用最下面那行 npm 的方式裝，兩條路裝出來的是同一個東西。
>
> 裝完打 `claude` 啟動，第一次會引導你登入。登入用的是你已經有的那個 Claude 帳號，跟桌面版同一個。如果沒有跳出引導，自己打 `/login`。
>
> 最後一塊是驗收，這一步請不要跳過。它只要三十秒，但它擋掉的是後面半小時的鬼打牆。用 `cd` 切到你前面做計時器的那個 `mission-timer` 資料夾，打 `claude`，然後問它一句：請幫我看一下這個資料夾裡有哪些檔案，並說明這個專案在做什麼。
>
> 它應該要講得出你的 `index.html`，還有計時器這件事。它講得出來，代表它真的讀得到你的檔案，不是在憑空猜。這個驗收動作之所以重要，是因為終端機版認的是「你現在站在哪個資料夾」，站錯地方它一樣會回你話，只是講的是別的專案的事。
>
> 底下那句也記一下：同一個資料夾，你今天用終端機、明天用桌面版，都可以，它們讀的是同一份檔案，不會打架。要離開終端機的對話就打 `/exit`。
>
> 然後是這一頁最重要的那句：裝到一半卡住，不影響你前面做的任何東西。回桌面版繼續就好。
>
> 安裝這種事卡住的原因通常跟你會不會無關，是你這台電腦的狀態跟示範的那台不一樣。不要在這裡跟它耗。

**這頁的教學意圖**：終端機版是同一個 Claude 的另一個介面；裝完一定要用「切到專案、問它一句」驗收讀得到檔案。
**預估時間**：8 分鐘（動手，含實機）

## Slide 45｜選修：模式切換、直通指令、喊停

**畫面**
開場一句說明哪些桌面版也有。三張卡片：`Shift + Tab` 執行模式切換器、`!` 直通終端機、`Esc` 喊停。最後一個灰底 Callout 講 `Esc` 退回的限制。

**逐字稿**

> 先分清楚哪些是終端機獨有的，免得你回桌面版找不到。三個裡面只有中間那個 `!` 是獨有的，換模式桌面版也做得到，只是點選單不是按鍵；喊停兩邊都有。
>
> 第一個，`Shift + Tab`，執行模式切換器。這是三個裡面最該記的，因為它管的是「它動手之前要不要先問你」。按一下換一個模式，狀態列會顯示現在在哪一個。
>
> Pro 跟 Max 方案開起來預設是 auto，全自動，它想做什麼就做什麼。按第一下切到 manual，每一步都要你點頭。再按是 acceptEdits，改檔案不問你，但別的動作還是會問。再按是 plan，只讀不改，它會把打算怎麼做講一遍給你看。再按回到 manual。
>
> 那個 plan 模式特別提一下，它做的就是「先講怎麼做，不要動手」。你要它改一個你還不確定該怎麼改的東西，先切到 plan 聽它講一遍，是很划算的動作。
>
> 這四個名字跟循環順序是會改的，Claude Code 更新蠻勤的。你按下去看到的跟我講的不一樣，那不是你按錯，以狀態列上顯示的為準。
>
> 第二個，`!`，直通終端機。你跟它講到一半，想自己下一行指令，例如看一下目前資料夾、測一下網路通不通，在行首打一個驚嘆號接你的指令，像 `!git status`，就直接跑了，不用退出 Claude 再進來。這個是終端機版獨有的。
>
> 第三個，`Esc`，喊停。你看著它往錯的方向走的時候，按一次，它手上的動作就停住，做到一半的東西會留著。
>
> 這一顆要養成反射。人在看它跑的時候有一種慣性，會想說「再看一下，說不定它自己會轉回來」，然後它一路做到底，你要收拾的東西就從三個檔案變成十個。
>
> `Esc` 還有第二種用法：輸入框空著的時候連按兩次，會把這次對話你送出過的每一句話列出來，選一個時間點退回去。等於整段對話的還原點。這件事打 `/rewind` 也一樣，那個指令桌面版跟終端機都能用。
>
> 最後這個灰框講的是那個還原點的邊界，不要誤會它的範圍：它只救得回 Claude 自己改的檔案。它用指令刪掉、搬走的東西救不回來。所以真正的保險還是動工前先用 Git 存一次檔，那個才管得到全部。

**這頁的教學意圖**：`Shift + Tab` 管的是動手前問不問你；`Esc` 的退回只涵蓋 Claude 改過的檔案，不等於備份。
**預估時間**：4 分鐘

### 1.【會過期】`11d2_M1_TerminalKeys` 的四個權限模式名稱與循環順序沒有查證日期

- 卡片內文寫著 auto → manual → acceptEdits → plan → manual 這個順序，以及「Pro 與 Max 方案預設在 auto」。這一類是 CLAUDE.md C-3 點名最容易過期的項目，而這個檔案的檔頭註解只記了拆頁的理由，沒有 C-1 要求的那三行（查證日期、當時現況、下次先重查哪裡）。
- 同一批資料也出現在 `30_Cheat_Perms`（Slide 62），兩頁要一起查，不然會出現同一份簡報自己講兩種順序。
- **建議**：兩個檔案各補上 C-1 的三行檔頭註解。逐字稿這邊已經口頭加了「以狀態列顯示的為準」當緩衝，但畫面上的字還是要對。

### 2.【缺漏】`11_M1_CodeSetup` 沒說登入要用哪一種帳號

- 畫面只寫「首次啟動會自動引導登入」。實際上這裡有兩條路（Claude 訂閱帳號，或 API 金鑰），選錯的人會開始被單獨計費，而這門課的付費模式要到章節五才講。
- **建議**：第三塊的小字補半句，「用你原本那個 Claude 訂閱帳號登入就好，不要填 API 金鑰」。理由不用展開，章節五會講。

### 3.【語法】`11_M1_CodeSetup` 的 `/exit` 用了 sky，A-1 規定斜線指令走 orange

- 同一塊裡 `cd`、`mission-timer`、`claude`、`Ctrl + C` 也全是 `text-sky-300`。這一頁把 sky 當成「等寬字的顏色」在用，但 A-1 的 sky 是強調色，標的是「這個現在重要」。
- 照 A-1：`/exit` 是斜線指令，要 orange；`cd`、`mission-timer`、`Ctrl + C` 是通用名詞，維持灰階（`text-slate-300`）；`claude` 是 Claude Code 的啟動指令，算專有名詞，orange。
- **影響**：不只是配色。現在整塊七個等寬字一樣亮，讀者看不出哪個是「Claude 的東西」、哪個是每台電腦都有的。第 21 行那個 `!` 已經是 orange 了，同一份簡報兩種標法。

### 4.【缺漏】章節四結束後沒有一頁把讀者送回主線

- Slide 45 是這一章最後一頁，下一頁就是章節五的分節頁。走選修這條路的人講完 `Esc` 就直接撞進新的一章，沒有任何一句話說「選修結束了」。
- 逐字稿這邊在轉場口頭補了一句，但翻講義的人看不到。
- **建議**：不要為此加一頁（B-2c 的理由）。`11d2` 最後那個 Callout 底下補半句，或在 `SlideLayout` 的副標區帶一句「選修結束」即可。
