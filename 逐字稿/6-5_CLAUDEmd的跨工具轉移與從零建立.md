## Slide 117｜網頁、Cowork、Claude Code 差在哪

**畫面**
上方一句提問與答案。中間一張三欄表：Claude Projects（網頁版 claude.ai／只有你上傳的檔案／不會動你的電腦）、Cowork（桌面版、輸入框上切到 Cowork／你綁的那一個資料夾／能讀能寫，不執行指令）、Claude Code（終端機，或桌面版的 Code 頁籤「你前面一直在用的那個」／整個專案資料夾／能執行指令、跑測試、版控），最後一列標為主色。兩個比較的欄位標在表頭：碰得到哪些檔案、能不能自己動手。

**逐字稿**（`meta.script`，41 秒）

> CLAUDE.md 是 Claude Code 在讀的檔案，但你不會每天都開它，有時候只是想在網頁上問一句話。換到別的地方，前面學的要重學嗎？不用。手冊怎麼寫、分層怎麼分、規則該放哪，三個地方都成立。會變的只有兩件事：它碰得到哪些檔案，以及它能不能自己動手，表上那兩欄就是這兩件。網頁版要用的話，在 claude.ai 開一個 Project，把手冊的內容貼進它的指令欄，那一欄每次對話都會帶上；上傳成檔案也可以，但那要它自己去讀。

**這頁的教學意圖**：三個介面的差別只有兩個維度（碰得到什麼、動不動得了手），寫法完全共用。

### 2.【矛盾】Slide 121 到 123 是三題，Slide 88 到 91 是四題，而且答案的排序反了

- 轉移演練的三題順序是：每次都要重講的（→ 根目錄）、違反了會出事的（→ Hook）、只在特定情況的（→ 子目錄）。
- 分流那一組的四題順序是：會出事的（→ Hook）、只在某一區的（→ 子目錄）、有固定步驟的（→ Skill）、以上皆非（→ 根目錄）。
- 兩組的順序幾乎完全相反，而分流那一組的口白特地強調「順序不能換，因為它是照擋得住的程度排的」。轉移這一組把最該先問的那一題放在第二個。
- 這一組的答案（Slide 124）順序也是照題號排的，所以三題的層次在畫面上是「軟、硬、中」，看不出階層。
- **建議**：兩種改法。把轉移三題的順序調成跟分流一致（會出事的先問），這樣兩組互相強化；或者在 Slide 121 或 Slide 124 加一句說明，講清楚這三題是「從最容易想得到的開始」而不是分流的順序。第一種比較好，因為這一段的職務就是證明同一套方法搬得過來。

### 3.【缺漏】轉移演練少掉了 Skill 那一層

### 4.【矛盾】Slide 117 的三個介面與 Slide 18 的「桌面版」指的不是同一個東西

- 這一頁把 Claude 的介面分成三個：Claude Projects（網頁）、Cowork（桌面版的一個頁籤）、Claude Code（終端機或桌面版的 Code 頁籤）。
- 但學員從 Slide 18（`10f_M1_DesktopFirst`）開始，一路到章節五寫手冊、掛 Hook，用的都是被稱為「桌面版」的東西，而照這一頁的分類那其實是「桌面版的 Code 頁籤」，也就是 Claude Code。
- 也就是說「桌面版」這個詞在這門課裡一直指的是 Claude Code 的一種開法，但這一頁把 Cowork 也叫做桌面版的一個頁籤。學員在這裡會開始懷疑自己前面一百頁用的是哪一個。
- **建議**：這一頁的第三列補半句點名，例如「Claude Code（終端機，或桌面版的 Code 頁籤，**也就是你前面一直在用的那個**）」。一句話就把前一百頁接住了。
- 這件事照 B-6 值得掃一次全片：`grep -rn "桌面版" src/slides src/slides-recorded` 看有沒有別頁也在用這個詞指不同的東西。
- **現況（2026-09-22 複查）**：`33_SurfaceIntro.tsx` 第三列**已補**「（你前面一直在用的那個）」。同一輪把這半句也補進 `meta.script`，因為聽的人只聽得到口白，而口白正好在「桌面版的 Cowork」後面接著講 Claude Code。全片 `桌面版` 掃過一次：其餘每一處指的都是 Claude Code 的桌面版，沒有別頁拿它指 Cowork。
