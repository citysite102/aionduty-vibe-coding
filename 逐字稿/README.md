# 逐字稿

一個錄製單元一個檔案，檔名是 `單元編號_單元名稱.md`。單元編號與範圍用 `npm run units` 查，**不要手抄**，搬頁之後 X-Y 會整批重排（CLAUDE.md B-2c）。

## 寫作前提

- **全片預錄、非同步自學**，鏡頭前沒有學員。不要寫「大家好」「各位同學」「我們今天來看」。
- **不要寫課務交代**：「等一下會發下去」「現在把電腦打開」「請按下一頁」。理由同 CLAUDE.md D-2。
- 投影片上已經有的字**不要整句照念**。逐字稿的職務是補充畫面沒寫的：為什麼、實例、常見的誤解。
- 每頁 45 秒是預錄拆頁的上限（`npm run check:rec` 會算），live 頁沒有硬性限制，但同一個節奏比較好剪。

## 檔案結構

每一頁三塊：

- **畫面**：這一頁上面有什麼，錄的時候對照用。
- **逐字稿**：照著念的內容。
- **【轉場 → 下一頁】**：上一頁講完到下一頁出現之間那句話。**錄的時候不要停**，這句是接的，停了剪接要另外補。

檔案最後一塊是 **待處理**，記這個單元在寫逐字稿時發現的投影片問題（矛盾、缺漏、語法）。寫逐字稿最容易撞到這些，因為要把畫面講成完整的話才會發現哪裡講不通。
