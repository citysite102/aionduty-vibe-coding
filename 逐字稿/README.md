# 逐字稿

一個錄製單元一個檔案，檔名是 `單元編號_單元名稱.md`。單元編號與範圍用 `npm run units` 查，**不要手抄**，搬頁之後 X-Y 會整批重排（CLAUDE.md B-2c）。

## 寫作前提

- **全片預錄、非同步自學**，鏡頭前沒有學員。不要寫「大家好」「各位同學」「我們今天來看」。
- **不要寫課務交代**：「等一下會發下去」「現在把電腦打開」「請按下一頁」。理由同 CLAUDE.md D-2。
- 投影片上已經有的字**不要整句照念**。逐字稿的職務是補充畫面沒寫的：為什麼、實例、常見的誤解。
- 每頁 45 秒是預錄拆頁的上限（`npm run check:rec` 會算），live 頁沒有硬性限制，但同一個節奏比較好剪。

## 敘事風格：照講師現場課的調性

風格基準是 `slide_1_41_現場教學逐字稿_設計檢查.md`（居家先生 AI 流程優化工作坊的現場稿）。那份是現場課，這門課是預錄，**借的是敘事邏輯與用詞，不是現場語**。

### 借過來的六件事

1. **先講學員現在的處境，再講內容。** 一頁的頭兩句先接住他為什麼會卡，而且要歸因到事情本身，不是歸因到他。<br>例：「很多人不是不努力學工具，而是工具本來就還在變。」<br>不要寫成後設導覽（「這頁很重要，因為⋯」），那是 CLAUDE.md D-2 禁的。同一件事講成內容就合法，講成簡報的結構就不合法。
2. **第一人稱表態。** 「我先講在前面」「我會把它理解成」「這裡先忍住」「我的判斷是」。講師的立場要出現，讀起來才不像說明書。
3. **連續短設問。** 抽象講完，丟三到四個具體的問題讓人自己對答案。<br>例：「資料從哪裡來？格式清不清楚？誰要接手？多久內要回應？」
4. **預判誤解，當場堵住。** 一句話講完，如果有一個很容易聽歪的方向，立刻補一句擋掉。<br>例：「它降低了理解門檻，但這不代表專業不重要，判斷與責任還是在人身上。」
5. **列點後面各跟一句白話。** 不要只給名詞。「保留，是這一步真的有價值，而且現在做法也合理。」
6. **收尾給判斷原則或順序，不給口號。**<br>例：「注意順序：消除、重新設計、加速、新增。不要一開始就加速。」<br>不是「答得出這三題，這一段就過了」那種（D-2 禁的收尾金句）。

### 用詞

白話動詞優先：卡住、忍住、硬做、回頭看、串回來、拿出來看、換掉、接住。不要為了正式而換成書面語。

術語第一次出現就用一句白話翻譯，不要讓人以為要背名詞。例：「Connector、API、Webhook，講白話就是系統能不能穩定把資料交出來。」

### 不借的

參考稿是現場稿，這幾類一律不跟：

- 招呼與點名：「大家好」「各位同學」「請大家」
- 現場調度：「等一下我們會⋯」「花 15 分鐘」「先猜猜看」
- 後設導覽：「這頁我們來看」「接下來三頁講⋯」

理由是這門課全片預錄、鏡頭前沒有學員（見上一節），以及 CLAUDE.md D-2。

## 檔案結構

每一頁三塊：

- **畫面**：這一頁上面有什麼，錄的時候對照用。
- **逐字稿**：照著念的內容。
- **【轉場 → 下一頁】**：上一頁講完到下一頁出現之間那句話。**錄的時候不要停**，這句是接的，停了剪接要另外補。

檔案最後一塊是 **待處理**，記這個單元在寫逐字稿時發現的投影片問題（矛盾、缺漏、語法）。寫逐字稿最容易撞到這些，因為要把畫面講成完整的話才會發現哪裡講不通。

## 預錄拆頁的逐字稿，照抄 `meta.script`

Slide 67 起有 53 頁是預錄拆頁（`src/slides-recorded/`），它們的檔案裡本來就有一份 `meta.script`，那才是錄製時要念的字，而且 `npm run check:rec` 會按「中文字數 ＋ 英文詞數 × 2」算長度，每頁上限 45 秒。

**這些頁面的逐字稿一律照抄 `meta.script`，不另外寫一份。** 理由是 CLAUDE.md A-4 記過的同一個坑：口白長度是從 `script` 算出來的，這裡另寫一份更長的版本等於製造第二份真相，而且錄的人照著唸會超時。

要改口白就去改那個檔案的 `meta.script`，改完跑 `npm run check:rec`。這份文件負責的是它旁邊那些欄位：畫面、教學意圖、轉場、待處理。

分節頁與座標頁（`kind: 'reference'`）不套 45 秒上限，但一樣有 `script`，處理方式相同。

## 章節三之後補的兩個欄位

3-x 的檔案每一頁多了兩行，之後的單元沿用：

- **這頁的教學意圖**：一句話。寫逐字稿之前先確定這一頁要帶走什麼，寫出來的話才不會散。
- **預估時間**：抓剪接與整支影片長度用。標「動手」的頁面含實機時間。

1-1 與 2-x 的檔案還沒補這兩行，之後回頭補。
